## TCP/TLS: matched carrier control

[96 cases / 24 exact-work ABBA blocks](carrier/summary.json), WSS/TCP/TCP/WSS,
polling and pushed replacement state, 1/2/4 upstream readers, 32 rows and 40
controlled steps. Same mTLS identity/source policy, JSON logical frames,
CachedPublisher, native fixture, Tmux pure profile, generic Reader/ReadGuard
and shared listener topology. Each block matches logical trace, consumer
admissions, native reads and proof/data counts. JSON bytes match in **all 24
blocks**; no timeout or cleanup failure was accepted.

Primary CPU is reader-driver plus publisher, normalized to delivered work.
Fixture-source acquisition and sampler CPU are separately recorded. Positive
percent below means lower TCP cost; negative means higher TCP cost.

| Mode | Readers | Median primary CPU reduction | Median accessible PSS reduction |
| --- | ---: | ---: | ---: |
| Poll | 1 | -2.62% | 0.21% |
| Poll | 2 | -0.84% | 0.25% |
| Poll | 4 | 0.73% | 0.15% |
| Push | 1 | 1.56% | 0.08% |
| Push | 2 | 2.36% | 0.03% |
| Push | 4 | 2.43% | 0.14% |

**Zero blocks** reached the frozen 15% CPU or 20% PSS improvement thresholds.
No block regressed over 5% CPU. These small mixed differences do not justify
another production carrier; they do not establish equivalence on every network
or show that binary encoding cannot help. No memory roles were inaccessible.
Uncontrolled background CPU ranged approximately 16–179% of one core, and
own CPU accounting is quantized at 10ms. The conclusion is bounded to this
matched loopback workload and prototype.

[Four longer-cadence cases](long-cadence/summary.json) form one additional
ABBA control: 12 changed steps at three-second intervals, one push reader,
original evidence already expired. Current rows stay empty while liveness and
fresh full proofs continue. TCP primary CPU is 0.74% higher in this single
block; it is a correctness/control result, not another four-block performance
qualification or ordinary fresh-fleet admission.

Full case inputs/counters/resources are in
[primary archive](carrier/matrix.json.gz) and
[cadence archive](long-cadence/matrix.json.gz); their summary files bind compressed
and raw hashes. Experimental TCP records pre-TLS framing/liveness counters.
WSS logical counters do not measure physical wire traffic. No framing-byte
percentage advantage is inferred from unlike counter scopes.

## Correctness and cleanup

[Validation record](validation.json) binds exact study checks and source inputs.
The TCP carrier passed 10 owned checks covering malformed length/prefix/JSON/
control, ALPN, certificates, admission bounds, nonce-before-native-read,
poll/push/reconnect, idle ping/pong without evidence renewal, missing pong and
policy revocation. Actual private Tmux owner checks passed poll, push, rename,
source loss and owner restart over **both** carriers. Separate interruption
checks canceled two-reader push trials for each carrier and required owned
teardown. Existing Tmux conformance/trace tests passed 15 cases.

The study reuses pinned WSS admission/policy/retirement implementation details;
this is version-pinned research, not a new supported listener API. There is no
production TCP endpoint, authority registration, negotiation, selection, rollback
or fallback implementation. Generic Reader's legacy SSH delivery label is a
common synthetic placeholder; it does not certify production TCP/WSS provenance.

Early harness setup retries corrected a policy-file mode (private 0600 is
required), WSS call/path usage, and the identity watch timeout assumption. None
were used as successful timing inputs. Decision matrix and cadence runs completed
without failed case records. This record preserves the failures' dispositions;
it does not claim every exploratory terminal log was retained.

No full Agent/native source suite, packaging/wheel gate, physical suspend,
real LAN/tailnet latency, slow-reader stress certification or operational
credential rollout was performed. There is no packaged-code/schema change to
justify a new wheel. Owned native and TLS evidence does not qualify ordinary
managed fleet deployment or endorse the experimental carrier for production.
