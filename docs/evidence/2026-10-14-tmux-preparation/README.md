## Disposition

SDK 1 and optional preparation interface 1 remain separate from package a18.
Observer owns the pure static domain rules; Mesh owns admission, delivery and
expiry. Owner certification is optional and introduces no Agent migration or
publisher prerequisite. The current Tmux consumer is already prepared at the
Observer composition layer. Future preparation adoption needs an actual repeated
Mesh-current workload and measured removed work, with lifetime and thread ownership
preserved. No transport, codec, release or managed deployment work follows merely
from this study. An intermittent pre-existing Observer refresh-fixture CI failure
is preserved in the owning receipt rather than claimed fixed by this Mesh change.
