# Releases and operations

The [0.1.0a25 prerelease](https://github.com/byebyebryan/mesh-plus/releases/tag/v0.1.0a25)
supports full Agent, working-set, Tmux and Host Mesh interfaces. It withdraws
standalone `agent-observer.mesh-active.v1` admission before binding/dispatch;
there is no alias or implicit conversion to working-set/full. Working-set
continues to cover active membership and recent context.

The frozen lock retains historical schema bytes. It is not a current capability
registry; the SDK/descriptor registry and explicit profiles determine support.

## Independent selections

The [deployment owner](https://github.com/byebyebryan/dotfiles/tree/main/deployments)
records exact collector/read/publisher, dashboard, Tmux and SSH-authority roles.
The Agent a9/Mesh a25 collector/working-set pair does not select a25 everywhere.
Source head, release build source, package qualification and installed bytes are
different records. Do not relabel/rebuild an old release from today's docs head.

Use `mesh-plus doctor` for installed metadata and
[diagnostics](../reference/diagnostics.md) for explicitly selected cached
assessment. Change only the intended role with reviewed artifacts/configuration;
preserve directional host authority, source binding and paired rollback inputs.
Verify installed readiness/recovery independently of source CI.

Ordinary readers retain complete views. WSS and the complete-view change feed
have separate opt-in/consumer gates. Semantic delta remains dark after failed
CPU/capacity qualification; old implementation plans do not resume it.
